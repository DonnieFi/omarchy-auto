# Theme background credits

`tokyo-night.webp` is **Tom Ballard’s Tokyo Studio** artwork, included with
Tom’s open-source permission (2026-11-02). See the repository
[`CREDITS.md`](../../../../../CREDITS.md) and [`docs/ASSETS.md`](../../../../../docs/ASSETS.md).

The other nine WebP files are resized and recompressed from the matching theme
`backgrounds/` directories in
[omacom/omarchy](https://github.com/omacom/omarchy/tree/master/themes).

Omarchy's repository is MIT-licensed. Individual photographs and illustrations
may have separate media rights; the theme configuration licence does not grant
redistribution rights for an image. These nine files are used for the private
Omarchy Auto demo. Verify each source image's rights before a public release or
public screenshot use.

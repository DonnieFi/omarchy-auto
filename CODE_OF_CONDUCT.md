# Code of Conduct

This project adopts the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Be respectful, assume good faith, keep it about the work. Harassment,
discrimination, and personal attacks aren't tolerated. The maintainer may
edit, hide, or remove comments, issues, and PRs, and block users.

Report conduct issues to the maintainer privately via [GitHub private reporting](https://github.com/DonnieFi/omarchy-auto/security/advisories/new) or a DM to [@dkfiander on X](https://x.com/dkfiander) (maintainer @DonnieFi).

# Security Policy

Report vulnerabilities privately via
[GitHub Security Advisories](https://github.com/DonnieFi/omarchy-auto/security/advisories/new) (GitHub private vulnerability reporting only; there is no security email). Do not open public issues or
PRs for unpatched vulnerabilities, leaked secrets, or exploit details; such
posts will be hidden and redirected.

## Scope
- The Android Auto app (`auto/`), phone launcher (`launcher/`), `core/`,
  `companion/`, and CI workflows in this repo.
- Out of scope: Android Auto / Google Play / OS bugs, sideloading risks the user
  chose, scanner output without a demonstrated impact.

## Supported versions
Only the latest alpha build on Play internal testing / latest `main`.

## What to include
Version/build, device + AA version, steps to reproduce, impact. No bounty;
credit given in release notes if wanted. Expect a reply within 7 days.
